Both algorithms, wrong models, unit errors, missing values, coordinate offsets, duplicate stations and a degenerate covariance.
Algorithm 1 (rail condition index: registration check, endpoint detrending, Šidák station and slope thresholds, field statistic with simulated thresholds) and Algorithm 2 (acceptance: C1–C3 and the GLS lever-arm criterion C4) are implemented as described in this study. Station consistency uses the ISO 13528 zeta score; the χ² consistency test follows Cox (2002); multiple comparisons use Šidák (1967). All computation runs in the browser; data never leave this computer. Program version v1.1.0 (2026-10-18).

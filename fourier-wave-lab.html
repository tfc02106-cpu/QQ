3拿「測試波」一個一個去試

方法很簡單：選一個波長，做一條紫色測試波，跟混合波逐點相乘。
・波長對上了 → 跟那條藏起來的波同上同下 → 綠色（正）比紅色（負）多，綠減紅不是 0
・波長不對 → 一下同向一下反向 → 綠、紅一樣多，綠減紅 ＝ 0
判斷方法：看圖下方的「綠色總面積」和「紅色總面積」兩條長條一不一樣長。

寫成數學式

混合波（兩條正弦波相加）：

y(x)=A1sin⁡(2πxλ1)+A2sin⁡(2πxλ2)

傅立葉：用波長 λ 的測試波去比對，算出「找到的振幅」

A(λ)=2L∫0Ly(x)·sin⁡(2πxλ)dx
  • y(x)·sin(2πx/λ)：就是下面圖上的「相乘」
  • ∫ … dx ÷ L：把綠色面積減紅色面積，再除以長度 L ＝ 平均
  • × 2：因為 sin² 的平均是 ½，乘 2 才剛好等於振幅
  • λ 對上 λ₁ 時 A(λ) ＝ A₁；λ 都對不上時 A(λ) ＝ 0

（完整的傅立葉轉換還會同時用 cos 去比對，用來處理波的起點不同；這裡兩條波都從 0 開始，所以只用 sin。）

4兩條都找到了？用 FFT 驗證

你一個一個試了 1～12。電腦用 FFT（快速傅立葉轉換）一次把所有波長都算完，畫成頻譜。山峰在哪裡，就有那個波長的波。

Ak=2N|∑n=0N−1yne−i2πkn/N|,λk=Lk

yn 是混合波取樣的第 n 個點；e−i… 就是同時用 cos 和 sin 當測試波。

這就是傅立葉：用不同波長的測試波去「問」：你裡面有沒有這個波長？有的話，相乘平均不是 0，還能算出它多大；沒有的話，就是 0。把每個波長都問一遍，就把混合波拆回原本的成分。

重點不是量幾 mm，而是每條波在 L 裡有沒有走完整圈。按下去會自動挑一個 L 示範：

  • 重點是「走完整圈」：L ÷ λ 是整數，每條波都剛好走完 → 山峰又尖又準。L 是 36 還是 72 都可以，只要圈數是整數。
  • L 不是整數倍：最後一段波沒走完，山峰會「漏」到旁邊，變矮變胖（洩漏）。
  • L 比波長還短：連一個完整的波都沒量到，FFT 找不到它。
  • 點距 Δx ＝ L ÷ N 要小於 λ ÷ 2：不然細紋會被看成一條假的長波（疊頻）。
  • FFT 能分辨的波長只有 L ÷ 1、L ÷ 2、L ÷ 3…，L 越長，可以挑的波長越密。

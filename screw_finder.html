教學說明與 A／B／C 協作分工

這是傳統影像處理的入門範本：灰階 → 3×3 均值濾波 → Otsu 二值化 → 形態學閉運算 → 連通區域 → 主軸長寬比例篩選。使用原生 HTML、CSS 與 JavaScript，不需 Python、API 金鑰或模型下載。

適用範圍：素色背景上、彼此分離且呈長條形的螺絲。這版沒有訓練螺絲辨識模型，不能判定物件種類、螺紋或瑕疵；端面朝上、重疊、反光強或背景複雜時可能漏判。框選表示「疑似螺絲」，沒有宣稱辨識準確率。示範圖為程式繪製，僅供操作與流程驗證。

操作：開啟相機並允許使用，按「拍照辨識」。相機受限制時可按「選取照片」，也可改用手機系統拍照。進入「手動修正」後，點既有框刪除；在照片空白處點兩個對角，補上一個框。按「重新偵測」會取代手動修正。

角色可練習的修改程式碼入口
A 同學濾波、門檻與形狀條件detectScrews()
B 同學蒐集真實照片驗證，之後替換為自訂模型detectScrews() 的回傳框格式
C 同學手機取像、畫框、操作介面startCamera()、render()
組長制定驗收條件、審查 PR、整合測試各手機操作與已知數量照片

每位同學從自己的分支修改，再開 PR 供互評。驗證時請記錄真實照片的 TP、FP、FN；示範圖通過不代表真實螺絲已通過驗證。相機串流會在拍照、關閉、切換頁面或離開時停止。照片及結果不會透過網路上傳；不會自動儲存到裝置。

手機相機請使用 HTTPS 網址，並以 Safari 或 Chrome 開啟。參考文件：MDN 相機 API、GitHub Pages HTTPS。
